# CSE4070: Software Frameworks

## Ders Bilgileri
* **Ders Kodu:** CSE4070
* **Ders Adı:** Software Frameworks
* **Dil:** İngilizce
* **AKTS:** 5
* **Ders Saati:** Teorik 3, Uygulama 0, Laboratuvar 0
* **Öğretim Elemanı:** -

## Ders Materyalleri
* **Zorunlu:** X Jia, "Object-Oriented Software Development", Addison Wesley, 2003.
* **Önerilen:** Gamma, Helm, Johnson, Vlissides, "Design Patterns", Addison Wesley, 1994.

## İçerik ve Amaç
Java programlama dilindeki farklı çerçevelerin (frameworks) özelliklerini öğretmek ve uygun çerçeveyi kullanarak yazılım geliştirmeyi sağlamak.
**Kapsam:** Nesne tabanlı modelleme, Koleksiyonlar (List, Set, Map), Overriding/Overloading, I/O işlemleri, İş Parçacıkları (Threads), AWT ve Swing çerçeveleri, Tasarım Paternleri.
