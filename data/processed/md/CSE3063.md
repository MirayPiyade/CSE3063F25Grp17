# CSE3063: Object Oriented Software Design

## Ders Bilgileri
* **Ders Kodu:** CSE3063
* **Ders Adı:** Object Oriented Software Design
* **Dil:** İngilizce
* **AKTS:** 6
* **Ders Saati:** Teorik 3
* **Öğretim Elemanı:** Çiğdem Eroğlu Erdem (cigdem.erdem@marmara.edu.tr)

## Ders Materyalleri
* **Kitap:** "Object-Oriented Software Engineering Using UML, Patterns, and Java", 3rd Ed., Bernd Bruegge, Allen H. Dutoit.

## Dersin Amacı ve İçeriği
Nesne yönelimli analiz ve tasarım, UML diyagramları, tasarım desenleri (design patterns), GRASP prensipleri.
