# CSE4288: Introduction to Machine Learning

## Ders Bilgileri
* **Ders Kodu:** CSE4288
* **Ders Adı:** Introduction to Machine Learning
* **Dil:** İngilizce
* **AKTS:** 5
* **Ders Saati:** Teorik 3
* **Ön Koşul:** Calculus, Linear Algebra, Probability, Programming skills.
* **Öğretim Elemanı:** Çiğdem Eroğlu Erdem (cigdem.erdem@marmara.edu.tr)

## Ders Materyalleri
* **Kitaplar:** Learning from Data (Abu-Mostafa et al.), Hands-On Machine Learning (Geron), Introduction to Machine Learning (Alpaydın) ve diğer referanslar.

## Dersin Amacı ve İçeriği
Gözetimli öğrenme (supervised), gözetimsiz öğrenme (unsupervised), lineer modeller, sinir ağları, SVM, Bayes karar teorisi, boyut indirgeme ve kümeleme.
